# 那天晚上骂 DeepSeek 的人，全骂错了

5 月 29 日晚上，DeepSeek 网页端悄悄变了。

同一条回答，点几次「重新生成」就提示用完了。输入框里改两个字想重发，也被卡了次数。没有公告，没有弹窗，用户是自己一头撞上才发现的。

接下来发生的事很熟悉：社交平台上骂声一片。骂它抠门，骂它变质，骂它「果然不行了」，骂「免费的就是用来恶心人的」。

我理解这种情绪。但这一次，骂的人几乎全骂错了对象。

因为只要你仔细看它**砍掉的是哪几个口子**，真相就藏不住了。

## 一、它没有降智，它在精准止血

先把现场还原清楚。

这次被限制的，不是「聊天」本身。你正常问问题、正常对话，额度该多少还是多少。被卡住的是三个非常具体的动作：

一是**重新生成**。同一个问题反复刷答案，几次就到顶。

二是**修改重发**。改一点输入再发一次，也被封了次数。

三是更早之前就已经关掉的**文件上传**（专家模式里的那个口子）。

把这三件事摆在一起，你会发现它们有一个刺眼的共同点：**它们都不是「人」在用的方式，而是「脚本」在用的方式。**

一个正常用户，一次对话用到三五次重新生成已经算多。会把「重新生成」「修改重发」「批量上传文件」这几个口子往死里用、用到撞上限的，根本不是来聊天的人。

DeepSeek 这一刀，砍得非常克制，也非常精准：它动的全是能被自动化批量调用的入口，唯独没动你正常说话。

这不像「降智」，这更像**止血**。

## 二、免费的救济粮，被人拿去卖了

那它在堵谁？

答案是一批靠它吃饭、却从没付过钱的人：**倒爷。**

具体怎么操作的？有人把 DeepSeek 的免费网页端，做成一个**反向代理**。

说人话就是：他们写一层程序，套在官方免费网页端外面，把这个本来只能你自己在浏览器里聊天的免费服务，伪装成一个标准的「DeepSeek API 接口」，然后挂出去，按量收费，卖给别人。

买家以为自己买的是 DeepSeek 的官方接口，其实背后是一堆脚本，在拼命薅 DeepSeek 免费网页端的羊毛。

这是什么概念？等于官方在街口免费发救济粮，本意是让普通人吃口饭。结果来了一帮人，推着小车把粮食整袋整袋拉走，转身摆个摊，加价卖给不知情的路人。

他们不消费，他们倒卖。他们薅的不是平台的钱，是本该留给真实用户的那份额度。

DeepSeek 关闭文件上传、限制重新生成和修改重发，砍的就是这帮人最依赖的几条流水线。

## 三、API 一点没动，这才是关键证据

如果你还觉得这是「DeepSeek 不行了」「算力扛不住了」，那有一个事实可以直接把这个说法摁住：

**它的官方 API，这次一点没动。**

没有限速，没有涨价，没有缩水。掏钱走正规付费接口的开发者，体验和之前完全一样。

这说明什么？说明 DeepSeek 的算力没有崩，服务也没有垮。它有能力、也愿意把资源稳稳地供给**真正付费、正常使用**的那一端。

被收紧的，从头到尾只有一个地方：**免费网页端里那几个被脚本薅穿了的口子。**

一个「快撑不住」的公司，会无差别地全线限流。而一个「被白嫖到忍无可忍」的公司，才会像现在这样，外科手术式地只切掉滥用的部分，把正常付费的主干完整保留。

这不是衰退的信号。这是一个被薅得太狠的免费服务，终于开始自我保护。

## 四、被连累的，是我们这些老实用的人

讲到这里，立场已经很清楚了。

我不打算各打五十大板。我也不打算补一段「当然 DeepSeek 也有沟通不到位的责任」来显得自己客观。这件事的因果链条非常清晰，就是一条直线：

**有人把免费额度做成反向代理倒卖牟利，把口子薅穿；DeepSeek 被迫收紧网页端来止血；而我们这些老老实实一次一次聊天的普通用户，跟着一起被限了。**

我们是被连累的那一方，不是被针对的那一方。

那些半夜骂 DeepSeek 抠门的人里，绝大多数是真实用户，是这件事真正的受害者。可他们的怒火，全浇在了那个其实在替他们挡刀的平台身上。而真正该被指着鼻子骂的倒爷，藏在代理后面，一声不吭，继续找下一个能薅的免费模型。

这才是这件事最让人不舒服的地方：闹得最凶的，和该负责的，根本不是同一批人。

## 写在最后

免费从来都不是没有代价。

它的代价不是不要钱，而是**总有人会把它薅到关停为止**。

DeepSeek 这次限次，砍的不是用户，是寄生在它身上的倒爷。它在用最克制的方式告诉所有人：救济粮还在发，但小车拉走整袋粮食的日子，结束了。

下次再看到一个免费的好东西突然变严，先别急着骂发东西的人。

先想想，是不是又有人，把它薅穿了。
